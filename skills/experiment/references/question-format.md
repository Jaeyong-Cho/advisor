# Question Format

When a skill needs to ask the user a question during its work, place each question in its own block:

```markdown
❓ **Q1** - **<question title>**: <question body>

➡️ <recommended answer>
```

Leave a blank line before and after the block. Number each question and include a recommendation. Batch related questions, and use [Grill Me](../../grill-me/SKILL.md) for a multi-round interview.
