# Research Topic Directory

When the user asks to file experiment output in the research wiki, list the existing `NN-*` topic directories under `~/wiki/today/research/` and recommend the matching existing topic or the next available number with a kebab-case slug. Confirm the directory before the first write of the session, then reuse it for the rest of that session.

Store experiment reports in that topic's `experiments/` directory and related facts or intents in `contexts/`.
