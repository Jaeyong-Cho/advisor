# Principles
A **principle** is a decision rule. It explains how to judge a situation.
Read the relevant principles first.

**Core**

- [**Bounded Autonomy**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-bounded-autonomy/SKILL.md). Defining direction, delegation, oversight, or rules for a system, or deciding whether to escalate a method choice.
- [**Define Goal**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-define-goal/SKILL.md). The expected outcome is unclear, you cannot explain the gap between current and expected state, or the definition of done is unknown.
- [**Incremental Progress**](skills/principle-incremental-progress/SKILL.md). Choosing the next development, refactoring, or workflow improvement; advance in a clear direction through small, complete changes and verify their effects before expanding.
- [**Guard the Context Window**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-guard-the-context-window/SKILL.md). Long files, large output, screenshots, or repeated reading are expanding the working context.
- [**Understand Through Abstraction**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-understand-through-abstraction/SKILL.md). Understanding a high-level flow, starting review or change, exploring unfamiliar code, or explaining unexpected behavior.
- [**Subtract Before You Add**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-subtract-before-you-add/SKILL.md). Adding code or structure during feature work, modification, or refactoring.
- [**Laziness Protocol**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-laziness-protocol/SKILL.md). Reviewing a refactor, change scope, new abstraction, layer, or value propagation.
- [**Minimize Reader Load**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-minimize-reader-load/SKILL.md). Code is difficult to trace, has one-caller wrappers, pass-through layers, or widely shared mutable state.
- [**Experience First**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-experience-first/SKILL.md). A product, UX, or feature-scope decision must prioritize the experience of end users and maintainers.

**Architecture**

- [**Foundational Thinking**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-foundational-thinking/SKILL.md). Choosing core types or data structures, sequencing foundations before features, or deciding whether concurrent actors can share state.
- [**Abstraction Levels**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-abstraction-levels/SKILL.md). Designing, implementing, or reviewing code that must separate intent, domain rules, and technical mechanisms.
- [**First Principle Redesign**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-first-principle-redesign/SKILL.md). Reviewing an implementation or considering a structural design change.
- [**Model the Domain**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-model-the-domain/SKILL.md). Writing stateful logic, repeated rule checks, coordinated flags, or repeated domain knowledge.
- [**Boundary Discipline**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-boundary-discipline/SKILL.md). Implementing external-input validation, error handling, or framework integration.
- [**Type System Discipline**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-type-system-discipline/SKILL.md). Designing or reviewing types and signatures in a statically typed language.
- [**Deep Module**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-deep-module/SKILL.md). Designing or reviewing module boundaries and interfaces.

**Verification**

- [**Fix Root Causes**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-fix-root-causes/SKILL.md). Fixing a bug, considering a symptom-only workaround, handling a repeated problem, or investigating a failure after restart.
- [**Closed Working Loop**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-closed-working-loop/SKILL.md). Starting feature work, a fix, or refactoring without an execution path that can show progress or provide timely feedback.
- [**Build the Lever**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-build-the-lever/SKILL.md). Repeating a change, analysis, or check, or when a result is hard to verify manually.
- [**Record and Resolve Friction**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-record-and-resolve-friction/SKILL.md). You find friction such as a code, structure, or interface smell, edge-case concern, or workaround.
- [**Encode Lessons in Structure**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-encode-lessons-in-structure/SKILL.md). The same instruction, review finding, test failure, or user correction repeats.

**Communication**

- [**Technical Writing**](https://github.com/Jaeyong-Cho/advisor/blob/645be080aa0bd92f8aad0f78c3835f9271f49667/skills/principle-technical-writing/SKILL.md). Writing or reviewing documentation, a README, design document, usage guide, PR description, or commit message.
